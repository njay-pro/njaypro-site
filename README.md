# Njaypro Site

Two-page personal site and launch surface for the Hermes Archetype Router.

## Source documents

- [`DESIGN.md`](DESIGN.md) — visual system, motion grammar, performance constraints.
- [`BUILD_BRIEF.md`](BUILD_BRIEF.md) — exact routes, copy, interaction requirements, and verification criteria.

## Development

The implementation is built with Vite, React, TypeScript, GSAP, p5.js, and Three.js.

```bash
pnpm install
pnpm dev
pnpm test
pnpm build
```

## Routes

- `/` — Njay / multidisciplinary builder.
- `/archetype` — Hermes Archetype Router.
